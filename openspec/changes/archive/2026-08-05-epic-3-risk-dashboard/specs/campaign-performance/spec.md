## ADDED Requirements

### Requirement: Actual vs Planned Risk/Reward Visualization
The system SHALL display a visual comparison between a Swing Campaign's planned risk/reward ratio and its actual realized risk/reward ratio.

#### Scenario: Comparing R/R on a completed campaign
- **WHEN** a user views a completed Swing Campaign that has a planned R/R value
- **THEN** the UI displays the Planned R/R side-by-side with the Actual Realized R/R
- **AND** highlights if the actual R/R fell significantly short of the planned R/R
