## ADDED Requirements

### Requirement: Data Table on Desktop
The system SHALL display positions in a dense data table when viewed on a desktop screen.

#### Scenario: View on desktop
- **WHEN** the dashboard is loaded with populated mock data on a desktop viewport
- **THEN** positions render in a dense data table

### Requirement: Responsive Cards on Mobile
The system SHALL collapse the data table into stacked cards when viewed on a mobile screen.

#### Scenario: View on mobile
- **WHEN** the dashboard is loaded on a mobile viewport
- **THEN** the table collapses into stacked cards
